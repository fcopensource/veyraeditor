# Changelog

## 1.0.0

First release of JSON Viewer Veyra for Chrome.

- JSON pages as a tree, with lazy drawing (200 items at a time) for big files.
- Exact big and exactly-written numbers.
- The path of every value, with copy path and copy value.
- Search with match stepping.
- Broken JSON: line, column, the line highlighted and the mistake explained.
- Raw (coloured, 2/4 spaces, tabs or one line) and Original views; copy and download.
- A page to paste JSON or open a file, from the toolbar button.
- Dark, light and automatic themes; the view, indent and theme are remembered.
