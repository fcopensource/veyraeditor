# Changelog

## 1.0.0

First release.

- Renames the paired tag as you type in an opening or closing tag, in HTML, JSX/TSX, Vue, Svelte, Astro, XML, PHP and templates.
- Handles nested tags, components, custom elements, fragments, attributes with > inside, comments, CDATA and script blocks.
- Undo keeps the pair in step; renames happen once alongside VS Code's linked editing.
- Leaves attributes, self-closing tags, invalid names, comparisons and multiple cursors alone.
