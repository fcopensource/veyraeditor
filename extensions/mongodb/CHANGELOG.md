# Changelog

## 1.0.0

First release.

- A lens above every MongoDB query in JavaScript, TypeScript and Python code, from explain() on your development database: documents read and returned, time, and the index used.
- Values your code computes at run time are filled with real values from the collection.
- Index suggestions with MongoDB's Equality, Sort, Range rule, created in one click or copied as Mongoose, Node.js, Python or mongosh code.
- Slow queries in the Problems panel, with quick fixes.
- Index Doctor: missing, unused and duplicate indexes, with sizes and use counts.
- Schema drift: Mongoose schemas compared with a sample of real documents.
- Queries and Collections views, and a status bar connection indicator.
- Connection strings in VS Code's secret storage; automatic connection to a local database from .env.
- Safety: explain only, time limits, confirmation before any change, and a read-only mode.
