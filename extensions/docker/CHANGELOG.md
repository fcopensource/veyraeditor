# Changelog

## 1.0.0

First release.

- Containers, Images, Volumes and Networks views, with Compose projects grouped and live updates from Docker events.
- Start, stop, restart, pause, remove, open a shell, open ports in the browser, inspect and copy IDs.
- Live Logs panel for containers and Compose projects: follow, filter, timestamps, problems only, colours, copy and save.
- Dashboard with live CPU and memory per container, disk use, and one-click cleanup.
- Compose Up, Down, Rebuild, Pull and Logs above compose files and for each service.
- Build and Build and Run above Dockerfiles.
- Dockerfile checks with quick fixes.
- Plain-English explanations for Docker errors.
- Works with Docker Desktop and Docker Engine, including Docker contexts.
