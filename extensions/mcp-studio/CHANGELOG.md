# Changelog

## 1.0.0

First release.

- MCP Servers sidebar showing the servers of VS Code, Claude Code, Claude Desktop, Cursor, Windsurf and GitHub Copilot CLI, for all projects and the open project.
- Add MCP Server page with a catalog of 20 popular servers, custom servers, and a connection test before saving.
- Inspector for tools, resources, resource templates and prompts, with forms built from input schemas, JSON results and the full message log.
- Plain-English explanations when a server fails to start or connect.
- Check All Servers, Copy to Other Apps (with variable syntax converted), Open Config File and Remove.
- Config files edited without losing comments or other settings, with a backup before every change.
- Secrets masked everywhere, with a warning when one is written in a project file.
