# Changelog

## 1.0.0

First release.

- The repository as a graph: branches as coloured lanes, merges, tags, remote branches and uncommitted changes.
- Branch labels with commits to push and pull.
- Commit details with changed files and their line counts; click a file for its diff. Ctrl+click to compare two commits.
- Right-click actions: check out, create a branch or tag, cherry-pick, revert, reset, merge, push, rename and delete, with a question before anything risky.
- Search by message, author or hash, a branch filter, Fetch, and keyboard navigation.
- Opens from the status bar, the Source Control view or Ctrl+Alt+G.
