# Changelog

## 1.0.0

First release of Project Manager Veyra.

- A Projects view with saved projects, Git repositories found on your disk, and recent folders.
- Shift+Alt+P to search all your projects and open one here or in a new window.
- Tags, grouping by tag, and sorting by name, recently opened or saved order.
- The current project in the status bar.
- Projects in a plain projects.json you can edit, keep in a synced folder, or bring from another project manager.
- An icon for the kind of project: Node.js, Python, Rust, Go, Java, .NET, PHP, Ruby, Dart and C/C++.
