# Changelog

## 1.0.0

First release.

- Errors, warnings and info at the end of their lines, coloured by severity, with the line tinted.
- The problem under the cursor in the status bar.
- The line you're typing on waits for a pause before its message shows again.
- Severity, source, message and file filters; a message template; follow-the-cursor modes; optional gutter dots.
- Commands to turn it on or off, show or hide warnings and info, copy or search the problem on a line, and hide a source.
- Theme colours you can change in workbench.colorCustomizations.
