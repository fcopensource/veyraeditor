# Changelog

## 1.0.0

- **Ports in Use** view: every port your programs listen on, with the program, its command line and working folder, grouped into This Workspace, Apps & Dev Servers, and Editors & Tools
- Recognises Vite, Next.js, Nuxt, Astro, SvelteKit, Angular, Create React App, Django, Flask, FastAPI, Rails, Laravel, Spring Boot, .NET, PostgreSQL, MySQL, MongoDB, Redis, Docker and more
- **Open in Browser**, **Copy Address**, **Stop** and **Reveal Working Folder** on every port
- **Free a Port…**: type a port number, see what holds it, stop it
- Safe stopping: confirmation, a fresh check that the program still holds the port, and Force Stop when needed. System services, other users' programs and code editors are never stoppable
- Status bar count and a notification when a web dev server starts in your workspace
- Remote SSH, WSL, Dev Containers and Codespaces support
- Light on resources: fast refreshes only while the view is visible, and none while VS Code is in the background
