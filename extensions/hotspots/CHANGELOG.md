# Changelog

## 1.0.0

- The Hotspot Map: every file as a tile, sized by lines of code and coloured by risk, with zoom, filter, hover details and a side panel for each file.
- Five colour modes: Hotspots, Change frequency, Complexity, Code age and Knowledge risk.
- Top Hotspots, Changes Together and Knowledge Risks in the sidebar.
- Flames on the hottest files in the Explorer, and the open file's rank in the status bar.
- Why Is This a Hotspot?, Open Files That Change With This One, and File History with each commit's diff.
- Copy a Markdown report.
- Choose the period: the last month up to all history. Refreshes after commits, pulls and checkouts.
