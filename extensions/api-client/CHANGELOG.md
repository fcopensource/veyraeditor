# Changelog

## 1.0.0

First release.

- Send REST and GraphQL requests with every method; Params, Headers, Body (JSON, text, XML, form, multipart, GraphQL) and Auth (Bearer, Basic, API key) tabs.
- Responses with status, time and size, pretty JSON, HTML and image preview, headers and the request that was sent.
- Collections saved as JSON in `.veyra-api/` in your repo, with folders and automatic saving.
- Environments with `{{variables}}`, built-in dynamic values, and private values kept out of git.
- History of sent requests.
- Import cURL and Postman collections; export to Postman; copy as cURL, JavaScript fetch or Python.
- Send Request buttons in `.http` and `.rest` files.
