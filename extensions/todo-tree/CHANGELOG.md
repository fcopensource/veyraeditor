# Changelog

## 1.0.0

First release.

- A Todo Tree panel with every TODO, FIXME, BUG, HACK, XXX and NOTE in comments, grouped by folder and file or by tag, with a count on its icon.
- Tags coloured in the editor and the scroll bar.
- Owners like TODO(@sam), a filter, and Copy as Markdown Checklist.
- Updates as you type, and when files are added, changed or deleted.
- Custom tags, include and exclude globs, and theme colours.
