## 1.0.0

First release.

- Automatic history: a snapshot when you open a file, on every save, and while you type (at most every 30 seconds).
- The Rewind panel: a timeline you can scrub, play back at 1x to 8x, and step through with the arrow keys.
- Changes since then, or the whole file as it was; restore a version (one Ctrl+Z undoes it) or compare it in the diff editor.
- Find Deleted Code across every file's history, and Restore a Deleted File.
- Checkpoints: name a moment and it's kept forever.
- Compressed, de-duplicated storage that thins out with age; dependencies, build output and lock files are never tracked.
