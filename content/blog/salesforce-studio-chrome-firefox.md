**[Salesforce Studio](/salesforce-studio) is now in the [Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-studio/goeclmlgbldldpcdhddkdpkjpohghafn) and [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/salesforce-studio/).** Installing it no longer means downloading a zip and turning on Developer mode: click **Add**, and it's ready.

## Every major browser

| Browser | Install from |
|---|---|
| Google Chrome | [Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-studio/goeclmlgbldldpcdhddkdpkjpohghafn) |
| Microsoft Edge | [Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-studio/goeclmlgbldldpcdhddkdpkjpohghafn) (click *Allow extensions from other stores* the first time) |
| Brave, Vivaldi | [Chrome Web Store](https://chromewebstore.google.com/detail/salesforce-studio/goeclmlgbldldpcdhddkdpkjpohghafn) |
| Mozilla Firefox | [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/salesforce-studio/) |

Firefox is new: Salesforce Studio now works there too.

## What you get from the stores

- **One-click install,** with no Developer mode banner on every browser start.
- **Automatic updates.** New versions arrive by themselves, so you always have the latest fixes.
- **Reviewed listings.** Both stores review extensions before they're published.

## What Salesforce Studio does

If you haven't tried it: Salesforce Studio opens your org's code in seconds, right from the Salesforce tab you're on. Click its icon on any Lightning, Setup, Classic or Visualforce page, and you get:

- Every **Lightning Web Component, Aura component, Apex class and trigger, and Visualforce page** in your org, in one searchable explorer.
- A real code editor with suggestions, formatting and error checking.
- **Ctrl+S saves straight to your org**, like Lightning Studio.
- **Review changes** before you deploy, with a diff and validation.

It uses the Salesforce sign-in you already have, and works in production and sandboxes. Read more in [the launch post](/blog/introducing-salesforce-studio).

## Moving from the zip version

If you loaded Salesforce Studio from a zip before:

1. Open `chrome://extensions` (or `edge://extensions`) and **Remove** the old unpacked version, so you don't have two.
2. Install it from the store.

Your settings are per browser profile, so set your preferences again the first time you open it.

Can't use browser stores at work? Every release is still on [GitHub](https://github.com/fcopensource/salesforce-studio-releases/releases), to load with Developer mode.
