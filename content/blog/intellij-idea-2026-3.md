JetBrains released **IntelliJ IDEA 2026.3 on November 5, 2026**, the last big update of the year for IntelliJ IDEA and the other JetBrains IDEs. Like VS Code and GitHub this season, there's an agent story, but there's also plenty for people who just write Java and Kotlin all day.

## Air: agents inside the IDE

IntelliJ IDEA now ships with **Air**, JetBrains' new layer for agentic development. Debugging gets an agent-friendly side too: an **ij-debugger agent skill** lets agents use the IDE's debugger.

## Java 28 and the Java stack

- **Java 28** support.
- **Jakarta Persistence 4** and **Hibernate 8**, plus a **Hibernate debugger**.
- **Spring Security diagnostics** in HTTP responses.
- **JaCoCo** is now the default coverage runner for new run configurations.

## Worktrees that just work

Git worktrees let you work on several branches at once, and they're how many people run coding agents side by side. 2026.3 **copies your local project configuration into new worktrees automatically**, so a fresh worktree opens ready to build and run instead of needing setup again.

## A new Home window, and remote work

- The **Home window replaces the Welcome screen**.
- You can **browse, create and edit files directly inside Kubernetes pods**.

## Java and Kotlin outside JetBrains

JetBrains also offers its Java and Kotlin code intelligence in **VS Code and Cursor**, through an LSP-based extension. It's a notable change of direction for a company whose IDEs were the only place to get that.

## 1,000+ fixes

JetBrains says the release includes more than **1,000 bug fixes**, plus hundreds of performance fixes. The **Big Data Tools** plugins are being deprecated, though Big Data Tools Core and Remote File Systems stay supported.
